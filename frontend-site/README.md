# Site vitrine Djua Energy

Site public de présentation des solutions solaires Djua : étude des besoins,
installation et suivi pour les particuliers, les entreprises et les sites
isolés en République démocratique du Congo.

## Développement

Depuis ce dossier :

```sh
npm ci
npm run dev
```

## Vérification de production

```sh
npm run build
npm run preview
```

Le site est une page vitrine avec navigation par sections et prise de contact
par WhatsApp, téléphone et e-mail.
